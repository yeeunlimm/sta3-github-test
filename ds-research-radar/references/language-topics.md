# 언어 AI 조사 범위

LLM, NLP, 다국어 모델, 임베딩, 추론, RAG, 합성 데이터, 경량화, 추론 효율, 정렬, 평가, 에이전트 평가, 멀티모달 언어 모델을 출발점으로 삼는다.

이 목록을 고정 분류로 쓰지 않는다. 최근 1차 출처에서 반복되는 새 문제·방법·평가 체계가 확인되면 별도 주제로 추가한다. 반대로 단지 유명하거나 자주 언급된다는 이유만으로 포함하지 않는다.

언어 도메인에서는 특히 데이터 수집·필터링·라벨 품질, 평가 설계, 모델 경량화·추론 비용이 데이터 사이언티스트 실무와 어떻게 이어지는지 확인한다.
