# Trend Radar

추세는 현재 수집 자료와 이전 수집 자료를 비교해 판단한다. 같은 제목의 중복 자료와 1차 출처가 없는 항목은 비교 대상에서 뺀다.

각 주제에서 논문, 모델, 기업, 행사, 채용, 데이터 공개의 신호 수와 신호 종류 수를 비교한다. 단순 키워드 등장 수는 쓰지 않는다.

| 분류 | 최소 근거 |
| --- | --- |
| Emerging | 이전 신호가 없고 현재 3개 이상, 서로 다른 종류가 2개 이상 |
| Growing | 이전 3개 이상이며 현재가 30% 이상 증가, 종류 2개 이상 |
| Established | 이전·현재 모두 4개 이상, 현재 종류 2개 이상 |
| Cooling | 이전 3개 이상에서 현재가 40% 이상 감소 |
| Unclear | 위 기준을 충족하지 못함 |

이 표는 읽기 우선순위를 돕는 기준일 뿐 시장 전체의 확정적 결론은 아니다. 수집 기간, 검색 범위, 출처 접근 범위를 함께 적는다.
