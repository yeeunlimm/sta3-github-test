# 논문 분석

중요 논문마다 제목, 저자, 기관, 발표일, 학회·저널, 1차 출처 URL과 **자료 성격**(동료심사 논문 / 사전공개 논문 / 기관 기술 글)을 적는다. 논문은 아래 목차 순서로 가능한 한 자세히 분석한다.

- **한 문장 요약:** 핵심 주장과 실제 의미
- **연구 질문:** 해결하려는 문제
- **사용 데이터:** 기간·언어·표본·해상도·분할 방식. 공개되지 않으면 공개되지 않았다고 쓴다.
- **사용 모델·방법:** 모델명, 버전, 아키텍처, 입력·출력, 학습·추론·평가 흐름을 원문에서 확인한 범위로 적는다.
- **새 모델 여부:** 새 모델·벤치마크·데이터·프레임워크 중 무엇을 만들었는지 분리한다. 새 모델이 아니면 그 사실을 명확히 쓴다.
- **비교 기준:** 기준 모델·기존 방법·평가 지표·실험 조건이 같은지 적는다.
- **새로움:** 이전 방법과 구분되는 실제 변화
- **핵심 결과:** 저자가 보고한 결과와 비교 대상
- **통찰:** 결과가 모델 선택·데이터 설계·평가 방식에 주는 의미
- **한계:** 저자가 밝힌 제한 또는 확인 가능한 일반화 한계
- **DS 의미:** 데이터 구축, 평가, 실험, 배포 중 무엇에 도움 되는지
- **연구 계보:** 이해에 필요한 이전 논문·모델만 링크

논문에 없는 모델명, 성능 수치, 아키텍처, 한계를 추정해 쓰지 않는다. 초록·공식 페이지에 모델별 정보가 부족하면 "공개 범위에서는 확인되지 않음"이라고 적고, 특정 모델의 우열을 단정하지 않는다.
